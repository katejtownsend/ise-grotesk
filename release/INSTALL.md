# Ise Grotesk v0.18 (draft test build)

Four fonts: Regular, Italic, Bold, Bold Italic. A display face (24pt and up). Not hinted yet, so small sizes on Windows may look rough.

**Install (Mac):** select all four .ttf files, right-click, Open, then click Install Font. (If an older Ise Grotesk is installed, remove it in Font Book first.)

**Install (Windows):** select all four, right-click, Install.

**Stylistic sets:** ss01 "Logic" (plain forms of the whimsy letters) and ss02 "Clear" (look-alike fixes). In Figma: Text, Typography, Details, OpenType features. In Adobe apps: OpenType panel, Stylistic Sets. In CSS: `font-feature-settings: "ss01"`.

**Report back:** note app, style, what you typed, and a screenshot.
